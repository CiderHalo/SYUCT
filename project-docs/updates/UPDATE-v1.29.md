# v1.29 官方全景按需加载与 QQ 加群弹窗

发布日期：2026-08-10

本版重点优化校园全景和交流群两个高频交互：校园全景不再进入地图页就连接第三方服务；QQ群入口统一为本站弹窗，由用户自行选择复制群号或调用 QQ 官方加群页面。

## 1. 官方校园全景改为点击后加载

进入 `map.html` 时只显示本站本地航拍封面。用户点击“开始浏览”后，页面才创建 720 云 `iframe`。因此只查看校园总图、快递地图或体育地图的用户不会自动加载第三方全景。

## 2. 本地航拍封面与移动端全屏承载

全景封面使用：

```text
assets/campus-panorama-cover.jpg
```

桌面端点击后在当前卡片中加载；手机端进入本站控制的全屏查看层，关闭时销毁 iframe 并返回地图页。本站不修改 720 云 iframe 内部的广告、按钮或其他跨域内容。

## 3. QQ 群入口恢复站内弹窗，但不再使用二维码

首页和 `about.html` 的交流群按钮不再点击后立即离开本站，而是先打开统一的加群弹窗。弹窗提供两种操作：

- **复制群号**：直接复制对应QQ群号
- **一键加入QQ群**：打开 QQ 官方生成的网页加群链接

二维码图片不再参与加群流程，`assets/qq-group.png` 可从仓库删除。

## 4. 两个群聊重新定位

### 2026 沈阳化工大学新生交流群

- 群号：`1170264357`
- 面向 2026 级新生
- 用于入学准备、校园日常、经验分享与资料互助
- 也可用于提交资料补充和纠错

### 沈阳化工大学百度贴吧官方群

- 群号：`596823406`
- 明确标注为沈阳化工大学百度贴吧官方群
- 用于校园日常、经验分享、贴吧话题以及校友同学交流

两个入口在“关于共建”页采用完全一致的卡片结构、标题层级和按钮样式，避免此前一侧主按钮、一侧次按钮造成的视觉不统一。

## 5. 加群弹窗按需创建

`assets/app.js` 只在用户第一次点击群入口时创建弹窗 DOM，普通页面访问不会额外创建加群界面。

弹窗关闭方式包括：

- 点击右上角关闭按钮
- 点击弹窗外遮罩
- 按 `Esc`

复制群号优先使用 Clipboard API，并保留兼容回退方式。

## 6. 新增加群补充样式文件

新增：

```text
assets/group-community.css
```

该文件只负责交流群双卡片和加群弹窗的补充样式，不改动全站 `styles.css` 的其他布局，降低对已有页面的影响。

## 7. 与 v1.28 的关系

v1.28 的快递导航结构继续保持：

```text
校园总图 → 快递取件 → 体育地图 → 官方全景
```

快递详情仍只在 `map.html#delivery` 维护。本版不改变地图、资料下载、搜索、PDF 阅读和 Office 本地预览逻辑。

## 发布后检查

建议重点检查：

- 首页“加入新生群”是否先打开本站弹窗
- 首页底部两个群按钮是否分别打开正确群信息
- 关于页两张群卡片是否等宽、同规格
- 新生群弹窗是否显示群号 `1170264357`
- 贴吧官方群弹窗是否显示群号 `596823406`
- “复制群号”是否可用
- “一键加入QQ群”是否分别进入正确 QQ 官方链接
- `assets/qq-group.png` 删除后页面是否仍正常
- 官方全景按需加载、手机全屏查看、搜索、PDF 与 Office 预览是否保持正常
