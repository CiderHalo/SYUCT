# 沈阳化工大学校园指南（SYUCT Campus Guide）v1.1

一个可直接部署到 GitHub Pages 的非官方学生共建资料站。

## 已包含

- 首页大图、站内搜索、深浅色切换与移动端侧栏
- 新生入学
- 校园地图与体育课地图
- 统一身份认证、WebVPN、CARSI、图书馆服务
- 培养方案、选修要求、微专业、期末真题
- 重修、查卷、奖学金、毕业资格、论文模板与查重
- 校历、体测、校园跑、学生管理规定
- 资料下载中心
- QQ 群二维码弹窗（1170264357）
- 4 张校园风景图

## GitHub Pages 部署

1. 新建公开仓库，例如 `SYUCT`。
2. 将本压缩包解压后的全部内容上传到仓库根目录。
3. 确保 `index.html` 与 `assets`、`docs` 同级。
4. 打开 `Settings → Pages`。
5. 选择 `Deploy from a branch`。
6. 分支选择 `main`，目录选择 `/ (root)`。
7. 保存后访问 `https://你的用户名.github.io/SYUCT/`。

## 目录

- `index.html`：首页
- `freshman.html`：新生入学
- `map.html`：校园地图
- `digital.html`：数字校园
- `academics.html`：学业资料
- `services.html`：办事大厅
- `campus.html`：校园生活
- `resources.html`：资料下载
- `about.html`：关于共建
- `assets/`：样式、脚本、地图、二维码和校园照片
- `docs/`：资料原文件

## 说明

本站为非官方学生共建站。政策、收费、考试、学籍和毕业要求以学校及学院当年正式通知为准。
